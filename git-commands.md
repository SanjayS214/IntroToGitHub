# Git Commands Cheat Sheet

- `git add` – stages changes so they're ready to be committed
- `git commit` – saves a snapshot of the staged changes with a message
- `git push` – uploads local commits to the GitHub repository
- `git pull` – downloads and merges the latest changes from GitHub
- `git stash` – temporarily sets aside unfinished changes
- `git checkout` – switches to a different branch or version
- `git branch` – lists or creates branches
- `git merge` – combines changes from one branch into another

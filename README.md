## Description

This repository is my practice space for learning **Git** and **GitHub** in CSCI 1000 at CU Boulder.
Version control tracks every change to a project, so you can see its history, undo mistakes, and work with other people without overwriting each other's work.

## What's Inside

- `README.md` - this file
- [`git-commands.md`](git-commands.md) - a cheat sheet of common Git commands with short explanations

## Installation

1. Install Git from [git-scm.com](https://git-scm.com/downloads).
2. Clone the repository:

   ```bash
   git clone git@github.com:SanjayS214/IntroToGitHub.git
   ```

3. Move into the folder:

   ```bash
   cd IntroToGitHub
   ```

## Usage

Open [`git-commands.md`](git-commands.md) when you need a quick reminder of a Git command. A typical workflow looks like this:

```bash
git checkout -b my-feature
git add .
git commit -m "Describe your change"
git push origin my-feature
```

Then open a pull request on GitHub to review and merge the change.
